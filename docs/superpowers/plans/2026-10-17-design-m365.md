# CRM UI – Microsoft-365-Design Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Das gesamte CRM-UI im Microsoft-365/Fluent-Design-Look gestalten – klare Linien, moderne Karten, Segoe-UI-inspirierte Typografie, blau-graue Farbwelt, und To-dos im Planner-Stil (Kanban-Board).

**Architecture:** Das bestehende CSS-System (basis.css + stapelweise Komponenten-Styles) wird um ein Fluent-Design-Token-System erweitert. Jede bestehende Klasse (`kd-*`, `knopf`, `af-*`) bleibt funktional erhalten, erhält aber neue visuelle Werte. Die To-do-Seite wird als Kanban-Board mit Spalten (Offen / In Arbeit / Erledigt) neu gestaltet.

**Tech Stack:** SvelteKit 2 + Svelte 5, CSS Custom Properties (Design Tokens), keine externen UI-Bibliotheken.

**Spec:** `docs/design-konzept.md` + Cans Vorgabe: „Gesamt wie Microsoft 365, To-dos wie Planner."

## Global Constraints

- Alle bestehenden Klassennamen bleiben erhalten (Rückwärtskompatibilität).
- Touch-Ziele mindestens 44×44 px (2,75 rem).
- Minimalbreite 360 px ohne horizontales Scrollen.
- Kontrast mindestens 4.5:1 für Fließtext.
- Fokus-Indikatoren immer sichtbar (`:focus-visible`).
- `prefers-reduced-motion` wird respektiert.
- Keine externen CSS-Frameworks – alles eigenes CSS.
- Inter als primäre Schriftart (Fallback: system-ui).
- Sprache: Deutsch, Du-Ansprache.

## Review Focus

1. **Kanban-Ziehen auf dem Handy:** Touch-Drag funktioniert zuverlässig, Scrollen wird nicht blockiert – Test in Task 5.
2. **Kontrast auf Windows-Hintergründen:** Bei Blau/Weiß-Mix muss Text lesbar bleiben – Test in Task 1.
3. **Brechpunkte:** Bei 360 px darf nichts horizontal scrollen – Test in Task 2.
4. **Bestehende Tests:** Nach jedem Task `npm run check && npm test` – keine Regressionen.
5. **Vorschau-Neubau:** Nach jedem Task `.vorschau-neubauen` anstoßen und Gesundheit prüfen.

  --m365-hintergrund: #f5f5f5;
  --m365-nav: #f0f0f0;
